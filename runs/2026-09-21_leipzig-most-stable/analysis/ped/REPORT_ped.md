# 안정 성층 보행자 수준 노출 — 중립 기준런 대조

`runs/2026-09-21_leipzig-most-stable` (Run A, 전이) / `runs/2026-09-23_leipzig-most-stable-meanflow` (Run B, 평균장)
대조군: `runs/2026-09-15_leipzig-dt01-sponge-uy` (+ `-meanflow`), 중립.

방법·정의·격자·그림 규격은 중립 분석과 **완전히 동일**합니다 (`runs/lambdap/deposition/ped_exposure.py`,
`ped_grid_fine.py`, `figures.py`). 노출 = 공중 LDM 입자가 z ≤ 2 m 에 머문 시간을 수평 격자에 적분한 값
[입자·s/m³], 침적 판정은 네 런 모두 `velocity == 0` (LDM VTK 에 `buffer_type` 필드가 없음).
t = 150–300 s, 1 s 간격 150 스냅샷, 소스당 방출 99,988 개.

## 1. 총량 — 성층에서 보행자 노출이 3배

| | 총 체류 [입자·s] | 입자당 [s] | 최대농도 [입자·s/m³] |
|---|---|---|---|
| 중립 A (전이) | 3,285,284 | 2.53 | 1,460 |
| 중립 B (평균장) | 3,382,287 | 2.60 | 1,446 |
| **안정 A (전이)** | **9,780,322** | **7.52** | **4,823** |
| 안정 B (평균장) | 8,790,184 | 6.76 | 4,078 |

소스별 배율 중앙값 **2.85×**, 범위 2.09–5.26×. 13개 소스 전부 증가.

## 2. 침적 감소가 아니라 연직 가둠이다

안정 런은 침적이 적어(t=300 s 침적률 14.9 % vs 중립 22.8 %) 공중 입자가 더 많이 남습니다.
이것이 노출 증가의 원인인지 분리했습니다.

| | 중립 A | 안정 A | 비 |
|---|---|---|---|
| 공중 입자 비율 (t=300 s) | 77.2 % | 85.1 % | 1.10× |
| 공중 입자 중 z ≤ 2 m (30 스냅샷 누적) | 4.19 % | **11.30 %** | **2.70×** |
| 곱 | | | **2.97×** |
| 실측 노출비 | | | **2.98×** |

곱이 실측과 일치합니다 — 3배 중 **1.10배만 침적 감소분**이고 나머지 2.70배는 연직 가둠입니다.
플룸 형상도 같은 말을 합니다 (t=300 s): 공중 입자 z 중앙값 20.2 → **10.2 m**, z90 56.6 → **35.3 m**.

## 3. 상관구조 — 총노출이 λp 와 양의 상관으로 전환

λp(75), 중정 소스(S3·S6·S10) 제외 n=10 Spearman.

| 고도대 [m] | 노출량 | 최대농도 | 노출면적 | 150 m 갇힘 | 평균거리 |
|---|---|---|---|---|---|
| 중립 0–2 | **−0.01** | +0.66 | −0.88 | +0.95 | −0.93 |
| 안정 0–2 | **+0.62** | +0.18 | −0.53 | +0.79 | −0.66 |
| 중립 5–10 | +0.41 | +0.84 | −0.95 | +0.96 | −0.95 |
| 안정 5–10 | +0.79 | +0.53 | −0.81 | +0.82 | −0.76 |

- **총노출**: 중립에서 λp 무관(−0.01)이던 것이 안정에서 **+0.62** 로 뒤집힙니다. λp(150) 기준으로도
  +0.45 (f20). 중립 분석의 "총노출은 도시형태와 무관" 이라는 결론이 **성층 조건에서는 성립하지 않습니다.**
- **면적·거리·갇힘**: 부호는 중립과 같지만 크기가 일제히 약해집니다 (−0.88 → −0.53, +0.95 → +0.79).
  성층이 플룸을 소스 근처에 묶어 놓아 형태 의존성이 희석되는 방향입니다.
- **셀 단위 거리밴드** (f26): 중립 −0.06 (25–75 m) → −0.62 (150–300 m) 의 부호 기울기가
  안정에서 −0.01 → −0.41 로 유지되되 완만해집니다. 구조는 견고합니다.

## 4. 고도대별 증폭 — 체커보드가 원인이 아니라는 근거

단위두께당 노출의 안정/중립 배율:

| 고도대 [m] | 0–1.5 | 0–2 | 2–5 | 5–10 | 10–20 |
|---|---|---|---|---|---|
| 배율 | 3.63× | 2.98× | 1.75× | 1.60× | 1.06× |

고도에 따라 **단조 감소**합니다. 이 런에 z=1.25 m 하강 편향(2Δz 홀짝 진동의 맨 아래 로브,
RUN.md 참조)이 있으므로 0–2 m 밴드만 인위적으로 부풀 가능성을 점검한 것인데, 만약 그것이
지배적이라면 진동이 부호를 뒤집는 z=3.75 m (2–5 m 밴드)에서 배율이 **꺾여야** 합니다.
실제로는 매끄럽게 감소하므로 성층에 의한 플룸 가둠이 주효과입니다.

**다만 0–2 m 밴드는 정확히 그 하강 로브 위에 있으므로 이 절대값은 상한으로 보아야 합니다.**
정량 확정은 `RIEMANN_EULERV` 구현 후 재실행이 필요합니다.

## 5. 전이 대 평균장

평균장(Run B)은 총노출을 안정에서 **10 % 낮게**(7.52 → 6.76 s), 중립에서는 **3 % 높게**(2.53 → 2.60 s)
추정합니다. 즉 평균장 근사의 부호·크기가 성층에서 달라집니다. 노출 면적(≥1 입자·s 셀 수)은
두 조건 모두 16,2xx → 10,711 로 **동일하게** 축소되어, 평균장이 지우는 것은 플룸의 공간적 퍼짐이지
총량이 아니라는 중립 때의 결론은 유지됩니다 (f36).
